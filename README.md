# 🛒 E-Commerce Website

A responsive and modern E-Commerce website built with **React.js** and **Tailwind CSS**.  
This project includes product browsing, category pages, product details, and cart functionality with a clean user interface.

## 🚀 Live Demo

🔗https://e-commerce-project-om3v.vercel.app/

## ✨ Features

- Responsive design for all devices
- Product categories (Men, Women, Kids)
- Product details page
- Add to cart functionality
- Remove cart items
- React Router navigation
- Context API for state management

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- React Router
- Context API
- Vite
